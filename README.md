# Smart Pantry Manager

Smart Pantry Manager is a Java Android application that helps users reduce household food waste by suggesting recipes based strictly on ingredients currently available in their pantry.

## Main Features

- Add pantry ingredients
- View pantry items
- Edit pantry items
- Delete pantry items
- Store pantry data in Firebase Cloud Firestore
- View suggested recipes
- Apply strict ingredient and quantity matching
- View recipe ingredients and preparation instructions
- Configure application settings

## Technology Used

- Java
- Android Studio
- XML layouts
- Firebase Cloud Firestore
- RecyclerView
- Android Activities and Intents

## Database Choice

Firebase Cloud Firestore was selected because it provides cloud-based data persistence, integrates with Android applications, supports real-time updates, and avoids the need to create a separate backend server.

## Setup Instructions

1. Install Android Studio.
2. Clone or download this repository.
3. Open the project in Android Studio.
4. Connect the project to the Firebase project.
5. Place the Firebase configuration file in the `app` folder.
6. Allow Gradle to synchronise.
7. Connect an Android phone with USB debugging enabled.
8. Run the application from Android Studio.
